# Map Teleport - Pure Lua Vehicle Test 0.1.5

这是独立实验版，尚未完成游戏内验证。它只使用 B42.21 原生 Lua 接口，无需 ZombieBuddy、Java JAR、启动参数或管理员模式。

## 人物与动物功能

已内置正式基础版的人物、携带动物、绳牵动物、原生离座和失败返回流程，无需再启用基础版。

- Teleport Here：传人物和携带动物，步行时带绳牵动物随行；车留原地。
- Teleport Vehicle Here [Pure Lua Test]：实验性远距离传车，支持单人存档内同车乘客（含 NPC）；先断开拖车。
- 备用键盘快捷键：Options → Key Bindings → Universal Map Teleport，绑定 UMTSP: Teleport Here (World Map)。坐车时弹出传人/传车两个选项。
- 人物传送与实验车辆传送不会同时执行。

## 本次怎么测试

1. 完全退出游戏。进入模组管理时，暂时关闭正式车辆扩展及 ZombieBuddy，避免已加载的 Java 桥干扰结果；本实验版会检查并拒绝调用现有 Java 桥。建议本轮只启用此实验版。
2. 启用 Map Teleport - Pure Lua Vehicle Test。
3. 使用可丢弃的测试存档，找一辆停稳的普通原版汽车，先独自测试，再带 NPC 乘客测试；先断开拖车。
4. 打开世界地图，右键一块空地，选 Teleport Vehicle Here [Pure Lua Test]。
5. 先测约 100 格，再测 1,000～3,000 格的远距离目的地。不要只测附近。
6. 传送途中会显示进度，可点取消或按 Esc，在当前已加载的停靠点结束。
7. 到达后人物正常下车并显示车辆地图标记。重新上车开一小段、离开该区域再返回，最后退出重进，确认车辆、后备箱物品与车辆状态仍在。

## 这版做了什么

- 远距离通过多个短步骤穿过连续加载区域，沿途寻找可容纳车辆的空地，不要求最终目的地预先加载。
- 人物在移动途中保留座位，避免 teleportTo 自动下车；结束时正常下车，避免切换人物时保留已卸载车辆的座位引用。
- 每一步先调用车辆原生更新，让区块车辆列表迁移完成，再移动人物和相机。
- 不重建、不复制、不删除车辆，不改车辆运行 ID 或数据库 ID。
- 结束时通过原生离座操作保存仍处于加载状态的车辆；不对已经卸载的车辆调用原生离座保存。
- 道路受阻或加载失败时停在当前已加载位置，不把人物强行传回远处的原点。

## 当前实验范围

支持单人存档内单车与同车乘客（含 NPC）的实验性传送。联网多人、牵引车队和特殊车辆尚未实现。
远距离是分段加载，并非瞬间完成。若沿线找不到可用落点，实验版会停止；它不是完整的跨地图寻路器。

## 已完成的离线验证

- 用游戏自身 Kahlua 编译器检查两份 Lua 文件：通过。
- 原生 Transform/getOrigin/Vector3f Lua 暴露检查：通过，不使用 ZombieBuddy。
- 模拟约 3,600 格、150 步的加载窗口移动：通过。
- 部分物理写入后发生异常的本步返回：通过。
- 取消、无可用路线、控制状态恢复：通过。
- 检测 Java 桥、拖车及不支持的乘客类型，在移车前拒绝：通过。

这些测试不代表真实游戏里的物理、区块卸载与重读存档已经验证。
